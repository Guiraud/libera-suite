# Entwickler

Libera Suite ist ein in Python geschriebener Host um die Editoren von Euro-Office. Die Editoren übernehmen den schwierigen Teil: eine `.docx`-, `.xlsx`- oder `.pptx`-Datei lesen und sie so setzen, wie ihr Verfasser sie gesehen hat. Der Host bringt alles Übrige einer Desktop-Anwendung mit: Fenster, Menüs, Dateidialoge, Formatkonvertierung und Paketierung. Alles andere stammt unverändert vom Original.

Die eigentliche Arbeit liegt deshalb an den Nahtstellen: was der Editor von seinem Host erwartet, wie der *Payload* gebaut wird — die Editoren und die nativen Binärdateien — und wie unsere Änderungen am Original als nachvollziehbare Patch-Reihe gepflegt werden.
