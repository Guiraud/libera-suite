# Ontwikkelaars

Libera Suite is een host in Python rond de componenten van Euro-Office. De componenten doen het moeilijke werk: een `.docx`, `.xlsx` of `.pptx` lezen en opmaken zoals de auteur het zag. De host levert de rest van een desktopapplicatie: de vensters, de menu's, de bestandsdialogen, de conversie tussen formaten en de verpakking. De rest komt ongewijzigd van upstream.

Het meeste werk zit dus op de naden: wat de componenten van hun host verwachten, hoe de *payload* gebouwd wordt (de componenten en de native binaire bestanden), en onze wijzigingen aan upstream, bijgehouden als een nagelezen reeks patches.
